# GANI FLOW · Layer G

디자인 파일과 작업 단계가 겹치며 하나의 흐름을 만드는 제품 성격을, 세 장의 레이어가 만드는 `G` 심볼로 표현한 1차 로고안입니다.

## 파일

- `gani-flow-mark.svg`: 앱 아이콘·파비콘용 심볼 원본
- `gani-flow-mark-dark.svg`: 어두운 배경용 3단계 바이올렛 심볼
- `gani-flow-horizontal.svg`: 기본 가로형 로고
- `gani-flow-monochrome.svg`: 단색 인쇄·각인용 로고
- `gani-flow-preview.svg`: 로고 조합과 크기별 확인 보드

## 기본 색상

- Wordmark Ink: `#0F172A`
- Deep Violet: `#5B21B6`
- Flow Violet: `#8B5CF6`
- Layer Lilac: `#C4B5FD`

SVG의 워드마크는 편집 가능한 텍스트로 유지했습니다. 최종 확정 뒤 실제 배포본에서는 사용 글꼴을 확정하고 글자 윤곽선 버전을 별도로 만드는 것을 권장합니다.
