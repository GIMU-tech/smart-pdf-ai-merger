# PDF 비교 엔진 사람 검수형 개편 계획

## 목표

기존 비교 엔진은 픽셀/도형 단위 차이를 너무 많이 보여줘서 사람이 검수할 때 중요한 변경을 고르기 어렵다. 앞으로는 기계가 찾은 세부 차이를 그대로 나열하지 않고, 사람이 먼저 확인해야 하는 의미 단위로 묶어서 보여준다.

## 우선순위

1. 제품 코드, 모델명, SKU처럼 식별 정보가 바뀐 경우 최우선으로 보여준다.
2. 치수, 규격, 중량, 단위처럼 인쇄물 오류 위험이 큰 수치 변경을 최우선으로 보여준다.
3. 주의/경고/안내 문구 변경은 별도 항목으로 보여준다.
4. 도면, 제품 그림, 구성품 그림의 세부 픽셀 차이는 한 묶음으로 요약한다.
5. 전체 대지 이동, 블록 이동, 미세 정렬 차이는 참고 항목으로 낮춘다.

## 구현 방향

- 워커는 기존 `diffs`를 유지하되, UI용 `reviewItems`와 `pageSummary`를 추가로 내려준다.
- 텍스트 OCR 결과는 개별 조각을 그대로 노출하지 않고 식별 정보/규격/문구 카테고리별로 묶는다.
- 큰 PDF는 전체 고해상도 OCR을 강행하지 않고 상단 핵심 영역을 작은 타일로 잘라 제품명/코드/규격 헤더를 우선 읽는다.
- 시각 요소 변경은 세부 후보 수를 유지하되, 검수 목록에서는 `도면/일러스트 변경` 카드 한 장으로 요약한다.
- 기존 원본 `diffs`는 남겨서 카드 클릭 시 첫 관련 위치로 이동할 수 있게 한다.

## 현재 반영 범위

- `workers/compare.worker.cjs`
  - 사람 검수용 요약 생성 추가
  - 텍스트 후보 카테고리화 및 묶음 처리 추가
  - 대형 페이지용 상단 타일 OCR 보강
  - 도면/레이아웃 후보 요약 처리 추가

- `src/features/compare/CompareTab.tsx`
  - 좌측 사이드바를 원시 변경 목록에서 사람 검수 요약 카드 UI로 변경
  - 필터를 `필수/중요/확인/참고` 기준으로 정리
  - 검수율 계산을 요약 카드 기준으로 변경

## 남은 개선 후보

- OCR 오독을 더 줄이기 위한 제품 코드 전용 보정 사전 추가
- 페이지별 처리 시간 표시와 타일 OCR 진행률 표시
- 사용자가 `세부 감지 N건`을 펼쳐 원시 diff를 볼 수 있는 상세 패널 추가
- 실제 제품군별 코드 패턴을 설정 파일로 분리
